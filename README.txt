BAKEUNITS WEBSITE PACKAGE
Domain: https://bakeunits.com
Contact: contact@bakeunits.com
Reference: https://www.bakemath.com/

Original BakeUnits website inspired by the general category of baking conversion tools. This package does not copy BakeMath's source code, branding, text, or assets.

FILES: index.html, cups-to-grams.html, measurement-converter.html, temperature-converter.html, recipe-scaler.html, conversions.html, about.html, contact.html, privacy.html, styles.css, app.js, robots.txt, sitemap.xml.

DEPLOY WITH GITHUB + CLOUDFLARE PAGES
1. Unzip this package.
2. Upload all files to the root of your existing GitHub repository (not the ZIP itself).
3. Commit the changes; Cloudflare Pages should deploy automatically if connected to this repository.
4. Visit https://bakeunits.com and test the tools on desktop and mobile.
5. Verify your domain in Google Search Console and submit https://bakeunits.com/sitemap.xml.

NOTES
- Check that bakeunits.com is connected to the correct Cloudflare Pages project and HTTPS works.
- The privacy policy is a starter template, not legal advice. Update it before adding AdSense, Analytics, forms, cookies, or other third-party services.
- No analytics or advertising scripts are included.
- Ingredient weights are estimates; use a scale when precision matters.
- Google Fonts is loaded externally by styles.css. Remove the @import line if you prefer no external font request.
