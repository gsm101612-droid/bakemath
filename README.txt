BAKEUNITS WEBSITE PACKAGE
Domain: https://bakeunits.com
Contact: contact@bakeunits.com
Static HTML/CSS/JavaScript site for GitHub + Cloudflare Pages.

Included:
- index.html: homepage
- cups-to-grams.html: ingredient-specific approximate weight calculator
- measurement-converter.html: common US volume converter
- temperature-converter.html: Fahrenheit/Celsius converter
- recipe-scaler.html: ingredient quantity scaler
- conversions.html: reference charts
- about.html, contact.html, privacy.html
- styles.css, app.js, robots.txt, sitemap.xml

DEPLOY:
1. Extract this ZIP on your computer.
2. Upload all files directly into the root of your existing GitHub repository. Do not upload only the ZIP and do not put them in a nested folder.
3. Commit changes. If Cloudflare Pages is connected to this GitHub repository, it should start a deployment automatically.
4. Test https://bakeunits.com and every tool on desktop and mobile.
5. In Google Search Console, verify your domain and submit https://bakeunits.com/sitemap.xml.

Notes:
- Domain and contact email are set to bakeunits.com and contact@bakeunits.com.
- Ingredient weights are estimates and should be verified before launch.
- Privacy policy is a starter template, not legal advice. Update it if you add analytics, AdSense, forms, or other third-party services.
- Original design inspired by the general category of baking conversion websites; it does not copy BakeMath.com source code or branding.
- No analytics or advertising code is included. AdSense approval is not guaranteed.
